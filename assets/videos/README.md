# Local highlight videos

Put locally sourced `.mp4` highlight mixtapes in this folder.

The page looks for files by player slug:

- `michael-jordan.mp4`
- `lebron-james.mp4`
- `kobe-bryant.mp4`
- `stephen-curry.mp4`
- `nikola-jokic.mp4`
- `luka-doncic.mp4`

If a file is missing, the player modal shows the exact filename it expects.

Current `.mp4` files are playable placeholders used to verify that every player modal can open video immediately.

For replacement links, see `SOURCES.md`.
